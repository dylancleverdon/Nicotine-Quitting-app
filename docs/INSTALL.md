# Installing Firewatch (one time only)

You only ever do this once. After that, Firewatch updates itself.

1. On your Android phone, open this link in Chrome:
   https://github.com/dylancleverdon/Nicotine-Quitting-app/releases/download/apk-latest/firewatch.apk
2. Chrome downloads `firewatch.apk`. Tap **Open** (or open it from your notifications or Downloads).
3. If your phone says Chrome isn't allowed to install apps, tap **Settings**, switch on
   **Allow from this source**, and press back.
4. Tap **Install**. If Google Play Protect warns that it doesn't recognise the app, tap
   **More details** and then **Install anyway**. (It's warning because Firewatch isn't from the
   Play Store.)
5. Open Firewatch. On the second setup screen, tap **Allow updates**, switch on
   **Allow from this source**, and press back.

That's it. New versions now download and install by themselves. Settings shows which version
you have and when it last checked.

**Your data** stays on your phone and is backed up automatically before every update. To keep
a copy somewhere else (for a lost or new phone), use **Settings → Export** and save the file to
Google Drive or email it to yourself. **Settings → Import** brings it back.
