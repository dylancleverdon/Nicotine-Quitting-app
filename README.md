# Firewatch by Baastik Labs

Know where your nicotine use really is, stay in control of it, and cut down if you want: a private tracker for Android and the web.

- **Install:** open [firewatch.apk](https://github.com/dylancleverdon/Nicotine-Quitting-app/releases/download/apk-latest/firewatch.apk) on the phone. Plain steps: [docs/INSTALL.md](docs/INSTALL.md).
- **Updates:** automatic. The app installs new versions by itself.
- **Web app (iPhone or any browser):** https://dylancleverdon.github.io/Nicotine-Quitting-app/
